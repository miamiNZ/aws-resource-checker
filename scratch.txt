AWS Resource Checker - command cheat sheet
==========================================

Replace my-profile with your own AWS CLI profile name.
Every make command has an npm equivalent - use npm if you don't have make.


SETUP (once)
------------
node --version
make install
npm ci
npx puppeteer browsers install chrome


AWS SIGN-IN
-----------
aws configure sso
aws configure list-profiles
aws sso login --profile my-profile
aws sts get-caller-identity --profile my-profile
aws sso logout


RUN THE REPORT
--------------
make
make run
make run PROFILE=my-profile
make run PROFILE=my-profile REGION=us-east-1
make sso PROFILE=my-profile

npm start
npm start -- --profile my-profile
npm start -- --profile my-profile --region us-east-1

npx ts-node src/application/app.ts --profile my-profile --region ap-southeast-2


BUILD
-----
make build
npm run build
make start PROFILE=my-profile
npm run start:dist -- --profile my-profile
make typecheck
npm run typecheck
make clean


REPORTS AND LOGS (bash)
-----------------------
ls -lt reports/
tail -f "$(ls -t logs/*.log | head -1)"
grep -h "\[ERROR\]" logs/*.log

REPORTS AND LOGS (PowerShell)
-----------------------------
Get-ChildItem reports | Sort-Object LastWriteTime -Descending
Get-Content (Get-ChildItem logs\*.log | Sort-Object LastWriteTime | Select-Object -Last 1) -Wait
Select-String -Path logs\*.log -Pattern "\[ERROR\]"

CLEAR OLD OUTPUT (bash, then PowerShell)
----------------------------------------
rm -rf reports/* logs/*
Remove-Item reports\*, logs\* -Recurse


MAINTENANCE
-----------
npm outdated
npm update
npm audit
npm audit fix
npx puppeteer browsers list


PROJECT LAYOUT
--------------
tree src /F /A
find src -type f | sort
